## 🧠 Key Takeaways

1. **Context engineering first** — good instructions make every subsequent prompt more accurate
2. **Plan before implementing** — Plan Mode prevents large, hard-to-revert mistakes
3. **Agents can see your app** — use the browser tool for real dogfooding feedback
4. **TDD with agents** — tests as a contract give you confidence to iterate fast
5. **Parallel > sequential** — independent tasks can run in parallel, saving real time
